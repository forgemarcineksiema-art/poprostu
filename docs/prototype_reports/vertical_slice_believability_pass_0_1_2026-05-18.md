# Vertical Slice Believability Pass 0.1 - 2026-05-18

## Decision

This pass starts the post-Phase-2R direction: stop adding pressure logic and make the existing route read like a first playable place.

Scope stayed intentionally narrow. No combat, police AI, new district, mission tree, input rewrite, or new runtime dependency was added.

## Implemented

- Added non-blocking route dressing generated by `PrototypeSceneBuilder`:
  - Barrio Hondo overhead street sign.
  - Safe return alley arch and painted arrow.
  - Laundry line, cloth pieces, balcony cluster, rooftop water tank, crate stack.
  - Rios checkpoint desk and awning.
  - Police roadblock barricades and warning stripes.
  - El Respiro workshop sign.
- Put required dressing on `CameraIgnore` with disabled colliders so it cannot shorten the camera, block movement, block vehicle exit, or alter route triggers.
- Extended `PrototypeSceneValidator` and EditMode tests so the route dressing is now an authored requirement.
- Added a reusable editor capture method:
  - `Valle de Plata/Capture Phase 1 Believability Overview`
  - output: `docs/prototype_reports/vertical_slice_believability_pass_0_1_2026-05-18.png`
- Fixed a route robustness bug exposed by the denser scene: after `Safe return` registers `PressureFailureEscape`, overlapping nearby start triggers can no longer overwrite the route outcome back to `PressureBlocked`.
