# Preprodukcja: gra o fikcyjnym Pablo i kartelach

Ten folder jest warstwą decyzyjną projektu. Nie opisuje jeszcze pełnej gry ani nie jest backlogiem kodowania. Jego zadanie jest prostsze i ważniejsze: ustalić, czym gra ma być, czym nie może się stać i jakie warunki muszą być spełnione, zanim zaczniemy produkować systemy, misje i content.

Hipoteza startowa: **Imperium z ulicy**. Gracz wciela się w fikcyjnego Pablo, ale archetyp jest czytelny. To TPP open world/sandbox o drodze na szczyt: od małego przemytnika do człowieka, którego boi się miasto, politycy i rywale. Gra nie ma być czystym GTA-chaosem, serialem z chodzeniem między scenkami ani tycoonem oglądanym z góry.

## Zasada pracy

Każdy etap kończy się artefaktem, który pozwala bezpiecznie przejść dalej. Jeśli późniejszy etap ujawni lepszy kierunek, wracamy do wcześniejszego dokumentu i aktualizujemy decyzję. Nie dopisujemy mechanik ani fabuły tylko dlatego, że brzmią efektownie. Każdy element musi wzmacniać główny temat: **narodziny imperium i cena władzy**.

## Co nie jest jeszcze zatwierdzone

- finalny tytuł gry,
- finalne imiona postaci i miasta,
- pełna fabuła kampanii,
- szczegółowe dialogi,
- pełny zakres świata,
- docelowy zestaw systemów poza vertical slice,
- docelowa lista assetów.

Robocze nazwy w dokumentach służą temu, żeby myśleć konkretnie. Można je zmienić bez kasowania założeń.

## Status preprodukcji

Obecny pakiet jest **v0.2 preproduction gate**, nie finalnym greenlightem pełnej produkcji. Style lock, protagonist brief, pierwszy porucznik i mission design doc dla “Pierwszego Frontu” są już rozpisane. Następny rozsądny krok to review tych czterech dokumentów przeciwko gate'owi w [11_preproduction_review_gate.md](11_preproduction_review_gate.md), a potem decyzja, czy zaczynać Faza 1: feel prototyp TPP/kamera/jazda.
